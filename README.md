# 工廠異常回報與維修派工系統

這是一個以工廠現場異常處理流程為情境的求職作品集專案，模擬產線發生設備故障、品質異常、缺料、換線延遲、停線或安全風險時，如何進行異常回報、主管確認、維修派工、處理追蹤與結案改善。

這個作品是「工廠生產製程追蹤 Dashboard」的延伸作品：第一個作品負責看生產狀態，這個作品負責處理現場問題。

## 使用情境

工廠現場常需要快速回答這些問題：

- 哪些異常還沒有結案？
- 哪些事件會造成停線或安全風險？
- 異常已經派給誰處理？
- 目前處理狀態是待確認、處理中、待料、已排除，還是待驗收？
- 哪些高風險案件已經接近或超過 SLA？
- 維修完成後是否經過主管驗收與結案確認？
- 異常原因與改善對策是否有留下紀錄？
- 哪些機台或異常類型最常造成停機？

本作品把上述流程整理成可操作的前端系統，讓使用者能新增異常回報、篩選案件、指派人員、推進處理狀態，並填寫 RCA、SLA 追蹤與主管驗收紀錄。

## Demo 功能

- 異常 KPI 總覽：未結案案件、停線事件、安全風險、平均停機時間、SLA 風險
- 新增異常回報：產線、機台、工單、異常類型、嚴重程度、回報人、問題描述
- 派工看板：待確認、已派工、處理中、待料、已排除、待驗收、已結案
- 案件篩選：依產線、狀態、嚴重程度篩選
- 案件明細：查看狀態、處理人員、停機時間與問題描述
- 維修派工：指派處理人員並推進處理狀態
- SLA 逾時提醒：依嚴重程度判斷處理時限，標示正常、即將逾時與已逾時
- 主管驗收結案：確認原因、處置與預防再發紀錄後留下驗收備註
- 處理歷程 Timeline：記錄建立回報、派工、狀態推進與 RCA 更新
- RCA 紀錄：填寫原因、處理方式、預防再發措施
- 本機資料保存：使用 `localStorage` 保存新增案件與操作結果
- 異常統計：異常類型排行、機台停機時間排行
